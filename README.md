# VoxSight

Watashi ga # KITA!
VoxSight is a a mobile application designed to optimize independent sight-reading practice for amateur choir members. 

## Setting up for FastAPI
1. Create Virtual Environment to the backend (python -m venv venv)
2. Install FastAPI Standard (on backend/requirements.txt)

## Dependencies Added (build.gradle.kts):
- com.squareup.retrofit2:retrofit:2.11.0
- com.squareup.retrofit2:converter-gson:2.11.0
- org.jetbrains.kotlinx:kotlinx-coroutines-android:1.7.3
